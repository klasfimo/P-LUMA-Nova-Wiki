# Controls

## Default keys

| Key | Action | Notes |
|---|---|---|
| Right Shift | Open the HUD editor | Works in game when no screen is open |
| C (hold) | Zoom | Zoom module, on by default |
| Left Alt | Free look | Free look module must be enabled; hold or toggle, see [Modules](Modules.md#free-look) |
| G | Toggle full bright | Full bright module must be enabled |

All of them can be changed under **Options → Controls → P-LUMA**.

If another zoom mod (Zoomify, Ok Zoomer, …) or free look mod is installed, P-LUMA doesn't register its own
key for that feature, so there's no conflict. See [Mod Compatibility](Mod-Compatibility.md).

## Command macros

Macro keys are set on the Command macros module page, not in the vanilla Controls screen. They can be any
keyboard key or the middle, right or side mouse buttons. See [Modules](Modules.md#command-macros).

## Opening the settings hub

- **Title screen:** P-LUMA Settings button (or the icon in the top right of the vanilla title screen)
- **Pause menu:** P-LUMA Settings
- **Mod Menu:** P-LUMA → settings

## HUD editor

| Input | Result |
|---|---|
| Drag | Move the element |
| Drag the bottom-right handle | Resize (0.5x to 3x) |
| Right click | Turn the element on or off |
| Gear icon | Open the element's settings |
| Arrow keys | Move the selected element 1 px |
| Shift + arrow keys | Move 10 px |
| Esc | Save and close |

## Chat search

| Input | Result |
|---|---|
| Magnifier at the end of the chat input | Open search |
| Type | Filter chat lines |
| Click a line | Copy it to the clipboard |
| Shift + click a line | Insert it into the chat input |
| Page Up / Page Down | Scroll results |
| Esc | Back to chat |
