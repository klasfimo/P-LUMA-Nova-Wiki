# P-LUMA Wiki

P-LUMA is a client-side Fabric mod: a drag-and-drop HUD editor, PvP-friendly modules, better chat and a
performance setup that works out of the box.

- **Current version:** Nova 1.4.5 · [What's new](Changelog.md#nova-145)
- **Minecraft:** 26.2 · 26.1–26.1.2 · 1.21.11 · 1.21.10 · 1.21.8 · 1.21.7 · 1.21.6
