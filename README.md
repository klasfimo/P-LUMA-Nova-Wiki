# P-LUMA Wiki

P-LUMA is a client-side Fabric mod: a drag-and-drop HUD editor, PvP-friendly modules, better chat and a
performance setup that works out of the box.

- **Current version:** Nova 1.4.4
- **Minecraft:** 26.2 · 26.1–26.1.2 · 1.21.11 · 1.21.10 · 1.21.8 · 1.21.7 · 1.21.6

- [Controls](Controls.md): every key binding

## Features

- [HUD Elements](HUD-Elements.md): all 23 elements and their options
- [Modules](Modules.md): crosshair, block overlay, hitboxes, zoom, free look, full bright, view model,
